# JP226Prints Prompt Studio

[Open the live studio](https://jp226prints-prompt-studio.jp226prints-au.chatgpt.site)

This public repository collects feedback, bug reports and feature requests for JP226Prints Prompt Studio. The site remains hosted separately; this repository contains feedback materials rather than the site source code.

## Give feedback

- [Report a bug](https://github.com/phantompants/jp226prints-prompt-studio/issues/new?template=bug_report.yml)
- [Suggest an improvement](https://github.com/phantompants/jp226prints-prompt-studio/issues/new?template=feature_request.yml)
- [Ask a question or discuss an idea](https://github.com/phantompants/jp226prints-prompt-studio/discussions)
- [View the issues register](https://github.com/phantompants/jp226prints-prompt-studio/issues)

A GitHub account is required to submit feedback. Include the studio page, your device/browser and enough detail to reproduce a problem. Screenshots and short prompt examples help. Remove API keys, personal information and confidential material before posting: feedback here is public.

## Studio pages

Vehicle Studio; Character Studio; Scene & Video Studio; Voice Studio; Logo & Brand Studio; CapCut Template Finder; Charity Rally Theme Planner; 3D Print Studio; Workflow / ComfyUI Export; Projects & Prompt Lab; Free API & LLM Resources.

The studio prepares prompts for use with your own AI tools. Research prompts and search links do not guarantee originality, live availability or complete social-media coverage.

## Tracking feedback

Bugs use the `bug` label and improvement requests use `enhancement`. Page and priority labels help organise the register. Open issues are outstanding; closed issues include completed work and items declined or superseded, with the reason recorded in the conversation.
